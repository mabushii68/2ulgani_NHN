## 2. 던전 구조 (신규 §2A)
```
[시작방] ─복도─ [전투방1] ─복도─ [전투방2] ─ … ─ [전투방6] ─복도─ [보스방]
```
- **선형 체인, 분기 없음.** 전투방 N = 기존 WaveConfig_N (스폰 구성·DDA 치환 그대로)
- 전투방: **24×14 고정** (스폰 링·교전 거리·DDA 임계 6/3.5 튜닝 보존). 방 간 차별화는 타일·조명 색 테마로만 — 전투 지형 변화 금지 (문답 Q2 우선순위 꼴찌)
- 복도: **순수 이동 통로** (문답 Q3=1). 짧게(8~12u), 연출은 타일·조명만. 인터랙션 없음
- 방 진입 → 문 잠김 + 스폰 시작 → **전멸 시 문 개방** (전멸형 종료 계약의 방 단위 번역)
- 시작방: 전공 선택 3택을 **바닥 마킹/제단 3개**로 배치 가능하면 배치, 일정 압박 시 기존 MajorSelect 화면 유지 (🟡)
- 보스방 진입 = BossIntro 트리거 (기존 유지)

## 3. 카메라 & 화면 밖 위협 보정 (신규 §2B)
- 추적: 단순 Lerp 팔로우 스크립트 (추가 패키지 금지 — Cinemachine 반입 불필요), 방 경계 클램프
- Orthographic Size **7.5 유지** (플레이어 스프라이트·탄 크기 체감 보존). 24×14 방에서 화면 밖 영역이 생기는 것이 전제
- **보정 2종 (계약 #1의 조건부):**
  1. 화면 밖 적: 화면 가장자리 방향 화살표 (엘리트·보스 = 마젠타, 일반 = 무채색)
  2. 마젠타 조준선·예측 마커: 발사자가 화면 안이면 조준선이 화면 밖까지 이어져도 **전체 렌더** (신규 계약 4로 발사자는 항상 화면 안이므로 조준선 시작점은 반드시 보임)
- Pixel Perfect 카메라는 시도하지 않는다 (D-3에 벌일 일 아님)

## 4. 상자 & 인터벌 대체 (신규 §2C)
- 방 클리어 → 문 개방과 동시에 **방 중앙에 상자 스폰** (열기 전 다음 방 진행 가능 — 스킵 허용, 단 되돌아오기 가능)
- 상자 인터랙트(접촉+키 또는 접촉 자동) → **timeScale 0** + 기존 UpgradePanel(3택 카드) + TARGET PROFILE + COUNTER PROTOCOL을 한 화면에 — **기존 WaveInterval 패널 UI를 오픈 연출만 바꿔 재사용**
- 감쇠(×0.8)·프로파일 스냅숏·DDA 판정 타이밍: 기존 `WaveEnded`(=방 클리어) 시점 그대로 — AIBrain 무변경
- 보물방·열쇠·상자 등급: **전부 컷** (문답 Q2=선형 체인)

## 5. UI 스킨 (건전풍 — 🟡)
- 참고 이미지의 **레이아웃 문법**만 차용: 좌상단 HP, 우하단 무기/전공, 픽셀 프레임. 건전 에셋 모방·유용 금지 (Franuka 팩 + 자체 제작으로)
- HP는 하트 변환하지 않고 **현행 바 유지** (HP 100 수치 체계 보존) — 프레임만 픽셀 스킨
- **AI 미니 패널은 정보 위계 최상위 유지** — 건전풍으로 바꾸더라도 마젠타 패널이 묻히면 안 됨 (킬러 기믹의 얼굴)
