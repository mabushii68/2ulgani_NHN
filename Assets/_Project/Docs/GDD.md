## 0. 게임 정체성

> **"AI는 당신의 플레이를 학습합니다. 그러니 AI에게 거짓말하세요."**

- 장르: 2D 탑뷰 아레나 웨이브 슈터 (Unity WebGL → GitHub Pages)
- 플레이 타임: 1회차 목표 **12분** (7웨이브 + 보스)
- 코어 루프: `습관 → AI 학습 → 카운터 → 역카운터 → 재학습`

**모든 적응 시스템의 3원칙 (위반 구현 금지):**
1. **읽을 수 있다** — AI가 무엇을 학습했는지 화면에서 안다
2. **예측할 수 있다** — 충분한 표본이 쌓였을 때만 AI가 신뢰도를 선언하고, 다음 카운터를 짐작할 수 있다
3. **조작할 수 있다** — 거짓 데이터를 심거나 습관을 깨서 AI를 속일 수 있다

## 1. 게임 플로우 & 상태

### 1.1 GameState (단일 씬 `Main.unity` 내 전환)
```csharp
enum GameState { Title, MajorSelect, Combat, WaveInterval, BossIntro, Result, Paused }
```
- `WaveInterval` = **AI 학습 패널 + 업그레이드 3택 1을 한 화면에** 통합 (상단: TARGET PROFILE / 하단: 카드 3장). 완전 일시정지(timeScale=0), 시간 무제한
- `Paused`: **ESC 토글.** Combat 중에만 진입 가능. 반투명 오버레이 + [계속 / 타이틀로]. 심사자가 중간에 멈출 수 있어야 함
- `BossIntro`: 웨이브 7 진입 시 2초 연출 후 Combat 복귀

### 1.2 화면 목록 (총 7)
Title → MajorSelect → Combat(HUD) → WaveInterval → BossIntro → Result → Pause 오버레이

### 1.3 게임 플로우
```
타이틀 → 전공 선택(3택 1)
 → [ 웨이브 전투(전멸 시 종료) → WaveInterval(학습 결과+업그레이드) ] × 6
 → BossIntro → 보스전(웨이브 7)
 → Result("AI가 학습한 나" 프로필) → 타이틀
```

### 1.4 종료 조건
- 승리: 보스 격파 → "축하합니다. 인간의 필요성이 24시간 연장되었습니다."
- 패배: HP 0 → "당신의 직업은 대체되었습니다."

## 7. AI 시스템 (킬러 기믹) — `AIBrain/` (순수 C#)

### 7.1 피격 위기 이벤트 (🔴 계약 — 모든 학습·판정의 원시 단위)
- **트리거**: 적 탄환의 충돌 예상 시간(TTI) **0.5초** 이내 진입 (탄환당 1회)
- **판정 확정** (트리거 후 0.6초 이내):
  - 피격 없이 최근접점 통과 → **회피 성공**. 탄환 진행 방향 기준 플레이어 변위를 투영해 LEFT/RIGHT 기록·학습
  - 피격 → **회피 실패**. 예측탄이었다면 "예측 적중" 집계
  - 좌우 변위 < 0.3유닛 (제자리/전후만) → 표본 **제외**
- 동시 탄막: TTI 최단 탄환 1개만 이벤트 처리 (표본 오염 방지)

### 7.2 회피 예측기 — 온라인 조건부 확률 모델 (🔴 계약: LEFT/RIGHT 2분류)
- 학습: 이벤트마다 LEFT/RIGHT 관측 카운트 갱신
- **Laplace smoothing**: 가상 카운트 (1,1) — 감쇠 없이 매 계산 고정 합산
- **지수 감쇠**: 매 웨이브 종료 시 **관측 카운트에만** ×0.8 (튜닝 0.7~0.9)
```text
P(LEFT) = (decayedLeftCount + 1) / (decayedLeftCount + decayedRightCount + 2)
```
- 관측 표본이 감쇠로 사라지면 확률이 50%로 자연 회귀 → "AI가 신뢰를 잃는" 동작이 수식에서 공짜로 나옴

### 7.3 신뢰도 이중 게이트 (`PredictorConfigSO`)
- `validSamples >= 8` (감쇠 후 **관측** 카운트 합, 가상 카운트 제외)
- `max(P(LEFT), P(RIGHT)) >= 0.70`
- 둘 다 만족 → **HIGH CONFIDENCE** (예측탄 활성). 하나라도 깨지면 즉시 일반탄 복귀 + HUD HIGH 배지 제거

### 7.4 예측탄 (Predictive Shot) — 확정 명세
- 사용 주체: 엘리트 + 보스만 (일반 적 ❌ — 읽는 주체가 식별돼야 심리전 성립)
- 빈도: HIGH CONFIDENCE 시 **공격 2회당 1회** (전탄 예측이면 100% 회피 가능해져 역으로 쉬워짐)
- 조준 공식:
```text
predictedTarget = playerPosition + predictedSideDir × offset   (offset = 1.5유닛, 튜닝값)
predictedSideDir = 탄환 진행 방향 기준, 학습된 우세 회피 방향의 단위 벡터
```
- 3단계 텔레그래프 (🔴 마젠타 규칙):
  1. **조준 0.35초**: 예측 지점으로 마젠타 점선 조준선 + 지점 원형 마커
  2. **발사**: 마젠타 탄 + 발광 트레일 (일반탄 = 주황/흰, 트레일 없음)
  3. **판정 ≤1초**: 적중 → 마커 위치 `PREDICTED` 소형 표기 / 회피 → `PREDICTION FAILED` (§10.3)

### 7.5 역카운터 판정 (3조건 전부 충족 시 1회)
1. 해당 예측이 HIGH CONFIDENCE 상태
2. 적이 실제로 그 예측으로 **예측탄을 발사**
3. 플레이어가 예측 **반대 LEFT/RIGHT로 회피 성공**하여 그 탄을 피함
- 확률표와 반대로 움직인 것만으로는 집계 ❌ — "읽고 깨뜨린 순간"만

### 7.6 학습 템포 목표 (플레이테스트 기준)
1. 1웨이브 습관 반복 → 다음 웨이브 유의미한 카운터 시작
2. 행동 변경 → 신뢰도 눈에 띄게 하락
3. 1~2웨이브 새 행동 누적 → 우세 방향 역전
- 감쇠 계수·최소 표본 수가 이 템포의 핵심 손잡이

- 1초 이내 종료. 긴 컷신 금지
- 보상: MVP는 무보상(연출+통계만). 재미 부족 시에만 1.0~1.5초 소량 버프 검토 (파밍 방지)

### 10.4 색 규칙 (🔴 계약)
**마젠타 = "AI가 나를 읽고 행하는 모든 것"** — 조준선·예측탄·엘리트 마커·보스 P2·장판. 그 외 위협은 무채색~주황. 플레이어 계열은 전공색(파랑/초록/노랑).

### 10.5 언어 규칙
- AI 시스템 발화 = **영어 대문자 터미널체** (`PREDICTION FAILED`, `COUNTER PROTOCOL`…)
- 인간 세계 = **한국어** (업그레이드명, 승패 메시지, 설명). 패널은 영어 시스템 텍스트 + 한국어 요약 1줄 병기

### 14.1 [P2.5] ML-Agents 보스 이동 정책 (사전 훈련 강화학습)
> 파이프라인: **ML-Agents(에디터 훈련) → ONNX → Unity Sentis(런타임 추론) → WebGL.** 런타임 학습이 아니라 사전 훈련 모델의 추론만 탑재한다.

**착수 조건 (전부 충족 시에만):**
- D8 WebGL 검증 통과 + §14 스트레치 상위 항목 판단 완료 + **잔여 기간 1.5일 이상**
- 미충족 시 시도 자체 금지 — 훈련은 반나절 만에 안 끝나는 작업이다

**적용 범위 (엄격 제한):**
- ⭕ **보스의 이동/포지셔닝 정책만** — 관측: 플레이어 상대 위치·속도, 보스 HP, 주변 플레이어 탄환 / 행동: 이동 방향
- ❌ 공격 패턴·텔레그래프는 스크립트 유지 — 3원칙 "예측할 수 있다"를 ML이 깨면 안 됨. 마젠타 규칙·예측탄 시스템도 그대로
- ❌ **회피 심리전(§7)의 대체 금지** — 사전 훈련 모델은 개별 플레이어를 학습할 수 없으므로 게임 정체성은 온라인 조건부 확률 모델이 계속 담당 (🔴 계약)

**구현 원칙:**
- 스크립트 FSM 보스를 **기본값으로 유지**, ML 정책은 `BossConfigSO`의 토글 뒤에 배치 — 훈련 실패/이상 행동 시 토글 하나로 롤백
- 훈련: 스크립트 플레이어 봇 상대 커리큘럼 (도망→추적→탄 회피 순). 목표는 "그럴듯한 압박 이동"이지 최적 플레이가 아님
- 검증: ONNX 모델을 WebGL 빌드에 포함해 Sentis CPU 백엔드 추론 프레임타임 측정 — 예산 2ms/프레임 초과 시 폐기
- 빌드 사이즈: 모델 < 5MB (전체 50MB 예산 내)

**심사 가치:** AI 기술 문서의 게임 내 AI 챕터가 "온라인 확률 학습(심리전) + 사전 훈련 심층 RL(보스 이동)" 2단 구성이 됨 — 단, 문서에는 실제 탑재된 것만 기재 (미탑재 시 시도·폐기 과정을 기록하는 것도 가치 있음)
