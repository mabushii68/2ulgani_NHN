게임 제목

러다이트 2026 (Luddite 2026)

AI는 당신의 플레이를 학습합니다. 그러니 AI에게 거짓말하세요.

한 줄 소개

적 AI가 당신의 회피 습관을 실시간으로 학습하고, 그 학습 결과를 화면에 숨김없이 공개한다. 플레이어는 자신에 대한 AI의 예측을 읽고 일부러 배신해서 살아남는 2D 탑뷰 던전 슈터.

이 게임의 핵심 — 무엇이 다른가

대부분의 게임에서 AI는 더 강해지는 방향으로 작동한다. 러다이트 2026의 AI는 더 정확해지는 방향으로 작동하고, 그 정확도를 플레이어에게 그대로 보여준다.

  1. AI가 당신을 관찰한다 — 적 탄이 당신에게 접근할 때마다, 당신이 왼쪽으로 피했는지 오른쪽으로 피했는지를 기록한다.
  2. AI가 확신을 갖는다 — 표본이 충분히 쌓이고 한쪽 편향이 뚜렷해지면 화면 우상단 패널이 바뀐다. AI MODEL: LEARNING... → AI READS: LEFT 73% [HIGH]
  3. AI가 그 예측대로 쏜다 — 확신 상태의 엘리트는 당신이 피할 자리를 향해 마젠타색 예측탄을 쏜다. 평소처럼 피하면 그대로 맞는다.
  4. 당신이 배신한다 — 조준선을 읽고 반대로 피하면 PREDICTION FAILED가 화면을 때리고, AI의 확신이 눈앞에서 무너진다. LEFT 82% → 64% · MODEL UPDATING...

즉 화면의 확률 표기가 곧 공략 정보다. 숨겨진 AI가 아니라 읽을 수 있는 AI를 상대한다.

게임 방법

목표

선형 던전의 전투방을 차례로 돌파하고 최종 보스 「거대 LLM」을 격파한다. 보스 2페이즈에서 AI는 당신에게서 학습한 것을 그대로 되돌려준다 — PATTERN: YOU: 당신의 교전 거리를 유지하고, 당신의 전공 무기를 마젠타로 복제하며, 당신이 좋아하는 구역을 선점한다. 🟡 (D7 구현 완료 — 최종 실플레이 검증 후 이 표기 제거)

조작

입력 동작
W / A / S / D 이동 (8방향)
마우스 이동 조준
마우스 좌클릭(홀드) 발사 — 누르고 있으면 자동 연사
ESC 일시정지

조작은 이 4가지가 전부다. 대시·구르기가 없기 때문에 회피는 오직 이동 방향 선택이고, 그래서 AI가 학습할 대상이 명확하다.

진행 흐름

타이틀 → 전공 선택(문과 / 이과 / 예체능)
   ↓
시작방 ─복도─ 전투방 1 … 전투방 6 ─복도─ 보스방
            (방 진입 시 문이 잠기고, 배정된 적을 전멸시켜야 열린다)
   ↓ 첫 방을 비우면
세부전공 선택 (전공당 3종) → 이후 내 탄환이 세부전공 테마로 바뀐다
   ↓ 이후 방을 비울 때마다
상자 획득 → 업그레이드 3택 1 + AI가 파악한 내 프로필 열람
   ↓
보스전 → 결과 화면 「AI가 학습한 나」
  • 세부전공 9종: 문과 = 어문계·상경계·법조계 / 이과 = 자연과학·공학·컴퓨터과학 / 예체능 = 체육·미술·음악. 선택하면 탄환이 전공 상징(연필·돈·책·숫자·번개·컴퓨터·공·붓·음표)으로 바뀐다.
  • 전멸형 종료: 시간이 지나서 끝나는 방은 없다. 버티기가 최적해가 되면 AI에게 줄 회피 데이터가 사라지기 때문이다.
  • 업그레이드 중 2종은 AI를 직접 겨냥한다 — 「행동교정」은 AI가 쌓은 관측을 지워버리고, 「논문조작」은 가짜 표본을 주입해 AI를 반대 방향으로 속인다.

종료 조건

결과 조건 화면
승리 보스 「거대 LLM」 격파 결과 화면 — AI가 학습한 당신의 프로필(별명·평균 교전 거리·회피 편향·AI 예측 적중률·역카운터 성공률)
패배 플레이어 HP 0 같은 결과 화면 (패배 표기)

승패와 무관하게, 결과 화면은 AI가 본 당신을 보여준다. 이 게임에서 최종 점수는 숫자가 아니라 프로필이다.

실행 방법

설치가 필요 없다. 브라우저에서 링크를 열면 바로 실행된다.

  1. 아래 플레이 링크를 클릭한다
  2. 로딩이 끝나면 화면의 [시작] 버튼을 누른다
  3. 전공을 선택하면 곧바로 던전이 시작된다
  • 권장 환경: Chrome / Edge 최신 버전, 데스크톱
  • 별도 설치·로그인·결제 없음. 실행 파일(.exe) 배포 없음
  • 키보드와 마우스가 필요하다 (모바일 미지원)
