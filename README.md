## 게임 방법
1. 전공(문과/이과/예체능)을 선택하고 선형 던전의 전투방을 차례로 돌파하세요. **방에 들어서면 문이 잠기고, 적을 전멸시켜야 열립니다.** 첫 방을 비우면 **세부전공**(전공당 3종 — 어문계·상경계·법조계 / 자연과학·공학·컴퓨터과학 / 체육·미술·음악)을 고르고, 내 탄환이 그 상징(연필·돈·책·숫자·번개·컴퓨터·공·붓·음표)으로 바뀝니다. 이후 방을 비우면 상자에서 업그레이드 3택 1.
2. 적 AI는 당신이 탄환을 **왼쪽으로 피하는지 오른쪽으로 피하는지** 학습합니다. 학습 현황은 HUD와 상자 오픈 시 **TARGET PROFILE** 화면에 항상 공개됩니다.
3. 신뢰도가 HIGH가 되면 엘리트·보스가 **마젠타색 예측탄** — 당신이 피할 곳을 미리 조준하는 탄 — 을 쏩니다.
4. 조준선을 읽고 **반대로 피하세요.** `PREDICTION FAILED` — AI의 신뢰도가 무너집니다.
5. 최종 보스는 P2 `PATTERN: YOU`에서 **당신의 플레이 스타일 자체**(교전 거리·전공 무기·선호 구역)를 복제합니다. 게임 내내 연마한 "AI 속이기"가 곧 생존기입니다.

- 승리: 보스 격파 / 패배: HP 0
- 플레이 타임: 약 12분

## 로컬 실행 / 빌드
- Unity **6000.3.7f1**, URP 2D Renderer + TextMeshPro (프로젝트는 URP 2D 템플릿 기반)
- `Assets/_Project/Scenes/Main.unity` 단일 씬 — 열고 Play
- 입력은 구 Input Manager API 사용 (Player Settings의 Active Input Handling = `Both`)
- WebGL 빌드: Compression **Gzip + Decompression Fallback**, 캔버스 1280×720
  - GitHub Pages는 `Content-Encoding: br`을 제공하지 않아 **Brotli를 쓰면 로딩이 실패합니다**
- 배포: `gh-pages` 브랜치(빌드 산출물 전용, orphan 커밋). 소스는 `main` / 작업 브랜치
