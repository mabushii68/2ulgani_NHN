## 게임 방법
1. 전공(문과/이과/예체능)을 선택하고 7웨이브의 적을 전멸시키세요.
2. 적 AI는 당신이 탄환을 **왼쪽으로 피하는지 오른쪽으로 피하는지** 학습합니다. 학습 현황은 HUD와 웨이브 사이 **TARGET PROFILE** 화면에 항상 공개됩니다.
3. 신뢰도가 HIGH가 되면 엘리트·보스가 **마젠타색 예측탄** — 당신이 피할 곳을 미리 조준하는 탄 — 을 쏩니다.
4. 조준선을 읽고 **반대로 피하세요.** `PREDICTION FAILED` — AI의 신뢰도가 무너집니다.
5. 최종 보스는 P2에서 **당신의 플레이 스타일 자체**를 복제합니다. 게임 내내 연마한 "AI 속이기"가 곧 생존기입니다.

- 승리: 보스 격파 / 패배: HP 0
- 플레이 타임: 약 12분

## 로컬 실행 / 빌드
- Unity **6 LTS (6000.0.x)**, 추가 패키지: URP, TextMeshPro
- `Assets/_Project/Scenes/Main.unity` 단일 씬 — 열고 Play
- WebGL 빌드: Compression **Gzip + Decompression Fallback** (GitHub Pages 호환)
